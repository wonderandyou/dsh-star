# dsh-star

DeepSeek Harness（DSH）插件：给每条回复打五颗星，攒下的评价能变成一条条可执行的规则。

## 它解决什么

模型这一轮答得好不好，你心里有数，但它不知道。下次还会犯同样的毛病，因为「你不满意」这件事没有落到任何地方。

这个插件把「打分」这件事变成闭环：

```
点星 → 这条回复被记下来 → 需要时让模型分析 → 给出可执行的改进 → 你勾选 → 写进 AGENTS.md
```

## 怎么用

1. 每条助手回复底部有五颗星，点一下就是打分
2. **不点就什么都不发生**——不发请求、不调模型、不写文件
3. 打了分之后，星星旁边出现「分析」
4. 点「分析」，模型会读这一轮的完整内容，给出 3~5 条改进建议
5. 勾选你认可的，点「加入规则」
6. 建议写进 `AGENTS.md` 的固定小节，之后每轮都会生效

## 模型怎么来的

**走宿主自己的通道**（`ctx.llm`），不需要任何 API key。

并且**跟随你当前会话正在用的模型**——你在界面上选哪个，它就用哪个，不会自作主张挑别的渠道去调。

## 数据在哪

| 东西 | 路径 |
|---|---|
| 评分记录 | `~/.dsh/star/ratings.jsonl` |
| 统计报告 | `~/.dsh/star/report.md` |
| 写入的规则 | `~/.dsh/AGENTS.md` 的 `## 从打分学到的偏好` 小节 |

规则小节会去重，最多保留 12 条，不会让 `AGENTS.md` 无限膨胀。

## 限制

1. **依赖宿主提供模型**——LLM 通道不可用时，「分析」会报错，但打分本身照常工作
2. **分析的是整轮内容**，不是单条消息：一轮回复会被拆成多个步骤（引导句 / 工具调用 / 正文），插件按 turn 编号把它们拼起来
3. **评分不影响模型行为**——分数只是记录，真正改变行为的是写进 `AGENTS.md` 的规则
4. **只写自己有权限的文件**，写前用临时文件 + rename，不会写出半截

## 安装

```powershell
dsh plugin add link:D:/path/to/dsh-star
```

装完**重启 DSH**（Host 半只在进程启动时加载）。

## 安全边界

- 只监听宿主自带的 webServer，**不另起服务、不开新端口**
- 写接口要求本机访问
- 读取会话记录只读不写
- 无第三方依赖、无外部网络请求
